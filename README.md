 # data_ops_course_101

Repositorio base para organizar artefactos y automatizaciones del proyecto.

## Estructura del proyecto

### `Migrations`
Carpeta destinada a los cambios de esquema, ajustes de datos y scripts de migración necesarios para evolucionar el proyecto de forma controlada.

### `docs`
Contiene la documentación del proyecto: guías, decisiones técnicas, notas de uso y cualquier información de apoyo para entender o mantener la solución.

### `workflows`
Incluye los flujos de trabajo automatizados, como procesos de CI/CD, validaciones, tareas programadas o integraciones que faciliten la operación del proyecto.

## Objetivo

Mantener una estructura clara para separar:

- cambios de datos o esquema,
- documentación del proyecto,
- y automatizaciones de proceso.
